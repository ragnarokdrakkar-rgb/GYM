# Workout Tracker 1.2.0 — Molten UI

Vključena uporabnikova zadnja predloga Gym-1.2.0-molten-ui.zip:
- Temen Molten UI, oranžno-zlat sij, SVG navigacija in plamen v glavi.
- Večji vnosi, gumbi za korake teže/ponovitev, trak opravljenih serij in obroč odmora.
- Pregled tedna, zložljiv arhiv dni in usklajena paleta grafov.
- Popravljena izbira dneva po arhiviranju; ponovna aktivacija uporablja varno shranjevanje in je blokirana med aktivnim/obnovitvenim treningom.

Obstoječi podatkovni model, varnostne kopije in izbrane vaje ostajajo. Nova nordijska ikona zaganjalnika ni del predloge in v tej izdaji še ni zamenjana.
