# Workout Tracker 1.0.50 — Forge UI

Ta izdaja prinaša popolno vizualno in strukturno prenovo aplikacije za Android in splet.

- Nov agresiven črno-rdeče-oranžen vizualni sistem.
- Nova glava aplikacije in kompaktna spodnja navigacija.
- Prenovljen command panel za naslednji trening.
- Velik Cut/Bulk blok je odstranjen z vrha treninga.
- Cut/Bulk se izbere samo v Nastavitvah; vaje, vrstni red in zgodovina ostanejo skupni.
- Prenovljeni session kontrolniki, tedni, dnevi, status treninga in fokus način.
- Vaje imajo jasnejšo hierarhijo, zaporedne številke, hitra dejanja in ločen panel delovnih serij.
- Serije, vnosi, gumbi, kartice napredka, obrazci, nastavitve in modali uporabljajo enoten sodoben dizajn.
- Mobilni modali so prikazani kot spodnji listi, desktop nastavitve pa uporabljajo dvostolpčni layout.
- Dodane so vidne focus tipke, zmanjšano gibanje in izboljšan ozki mobilni prikaz.

Funkcionalno pravilo ostaja nespremenjeno: Cut in Bulk prilagodita samo cilje setov, ponovitev in RPE. Ne zamenjata izbranih vaj.
